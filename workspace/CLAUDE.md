# SRI Workspace — คู่มือสำหรับ Claude Code

แอปภายในของพนักงาน SRI แยกจาก SRI OS อยู่ในโฟลเดอร์ `workspace/` เท่านั้น
อ่าน `docs/HANDOFF.md` ก่อนเริ่มงาน และดูหน้าจอใน `mockup/`

## ขอบเขตปัจจุบัน

ทำ **HR ลงเวลาเข้า-ออกงาน** ก่อน งานอื่นอยู่นอกขอบเขตจนกว่าลูกพี่สั่ง

## กฎเหล็ก

1. ห้ามแก้ไฟล์นอก `workspace/` ถ้ายังไม่ได้รับอนุมัติ
2. ห้ามแตะ Ledger และตารางการเงินของ SRI OS
3. ห้ามใช้ service-role หรือ secret key ในแอป ใช้ publishable key + RLS + RPC เท่านั้น
4. เวลาเข้า-ออกงานต้องมาจากเซิร์ฟเวอร์ ห้ามเชื่อเวลาจากเครื่องผู้ใช้
5. ห้าม DELETE หรือแก้ทับ `time_entries` การแก้ไขต้องเป็นรายการใหม่พร้อมเหตุผลและ Audit Log
6. ขอ GPS และกล้องหลังผู้ใช้เห็นประกาศและกดยินยอมแล้วเท่านั้น
7. ติดตามตำแหน่งเฉพาะตอนกดลงเวลา ห้ามทำ Background Tracking
8. รูปเซลฟี่อยู่ Private Bucket เปิดด้วย Signed URL อายุสั้น
9. ใช้ระบบ Role/Permission เดิมของ SRI OS ห้าม hard-code ชื่อ Role
10. ห้าม commit `.env*`, ข้อมูลพนักงานจริง หรือข้อมูลการเงินจริง

## UI

- ไทยเป็นหลัก ฟอนต์ IBM Plex Sans Thai
- เนื้อหาหลัก ≥ 18px, ข้อความรอง ≥ 16px, ปุ่ม ≥ 52px และมีข้อความกำกับ
- ออกแบบมือถือก่อน
- สี: `#004AAD`, ตัวอักษร `#0A2540`, พื้น `#F6F9FC`
- วันที่ `DD/MM/YYYY` ปี ค.ศ.
