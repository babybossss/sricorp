ประเมิน ณ 06/10/2026 · ปรับได้ตลอด แก้ไฟล์นี้แล้ว commit

## ตอบคำถาม: ทำไปก่อนได้ไหมระหว่างลูกพี่กรอกข้อมูล

**ได้ และควรทำ** — งาน 80% ไม่ต้องรอข้อมูลจริง เพราะทดสอบด้วยข้อมูลตัวอย่างได้

| ต้องรอข้อมูลลูกพี่ | ทำได้เลย |
|---|---|
| ตรวจว่ายอดตั้งต้นกระทบยอดจริง | ตัว importer เอง |
| ตัวเลขในรายงานถูกไหม | ทุกหน้าจอ ทุก logic ทุกเทสต์ |
| ล็อต FIFO ของจริง | ตัวคำนวณ FIFO |

**ข้อควรระวัง**: อย่าให้ผมเดาโครงสร้างข้อมูลที่ลูกพี่ยังไม่ได้ยืนยัน — ถ้าเดาผิด
ต้องมาแก้ข้อมูลที่ import ไปแล้ว ซึ่งแพงกว่าการรอ

## ต้นทุน token

จากที่ใช้จริงในโปรเจกต์นี้:

| รายการ | token |
|---|---|
| ฟีเจอร์หนึ่งชิ้น (เขียน + เทสต์ + ทดสอบใน browser) | 50–150k |
| ตรวจโดย mace-windu หนึ่งรอบ | 60–120k |
| ฟีเจอร์ที่แตะเงิน (มักตรวจ 2–3 รอบ) | 200–400k |

**ประเมินทั้งโครงการ: 4–7 ล้าน token**

**ตัวที่กินจริงไม่ใช่การเขียนโค้ด แต่คือรอบตรวจ** — เซสชันที่ผ่านมา mace-windu BLOCK 5 ครั้ง
แต่ละครั้งเจอของจริงที่ทำให้ตัวเลขผิดเงียบๆ (ดอกเบี้ยหาย · ตัดทรัพย์ผิดราคา ·
เงินของคนหนึ่งโผล่ในงบอีกคน · ปุ่มบันทึกข้ามกติกานิติบุคคล · ตัวแปลงเลขสลับเครื่องหมาย)

**นี่คือค่าใช้จ่ายที่คุ้มที่สุดในโปรเจกต์** ถ้าตัดออกเพื่อประหยัด จะได้ระบบที่ตัวเลขผิด
โดยไม่มีใครรู้ ซึ่งแพงกว่ามากสำหรับระบบบัญชี

## ข้อที่ลูกพี่เน้น: ต้องอัปเดต/ต่อยอดได้

สิ่งที่ทำไปแล้วเพื่อข้อนี้ และต้องรักษาไว้

### 1. กฎอยู่ที่เดียว ไม่กระจาย
`src/lib/rules/` คือแหล่งความจริงเดียว — ผังบัญชี · คู่บัญชี · โครงงบ · หมวดทรัพย์
หน้าจอกับฐานข้อมูลอ่านจากที่นี่ทั้งคู่

**เซสชันนี้เจอรูปแบบเดิมซ้ำ 5 ครั้ง** ที่ข้อมูลชุดเดียวกันถูกเขียนไว้สองที่แล้วไม่ตรงกัน
(คู่บัญชีในฟอร์ม · กติกาที่ปุ่มบันทึก · โครงงบ · สัดส่วนหน้าแรก · รายชื่อผู้ถือในเทมเพลต)
ทุกครั้งอาการเหมือนกัน: **หน้าจอดูปกติ แต่ตัวเลขผิด**

### 2. เทสต์เป็นตัวกันการถอยหลัง
190 เทสต์ ส่วนใหญ่ไม่ได้ทดสอบว่า "โค้ดทำงานไหม" แต่ทดสอบว่า
**"ยอดหายไปจากรายงานได้ไหม"** · เพิ่มบัญชีแล้วลืมใส่ในงบ = เทสต์พัง ไม่ใช่ยอดหายเงียบๆ

### 3. ทุกการตัดสินใจมีเหตุผลและวิธีย้อนกลับ
`docs/DECISIONS.md` 58 ข้อ · ลูกพี่ไม่เห็นด้วยข้อไหน เปิดอ่านได้ว่าทำไมถึงเลือกแบบนั้น
และต้องแก้ตรงไหนถ้าจะเปลี่ยน

### 4. migration เดินหน้าอย่างเดียว
แก้ฐานข้อมูลผ่านไฟล์ที่ commit ไว้ ไม่แก้มือ — ย้อนกลับได้และรู้ว่าใครแก้อะไร

### 5. สภาเจไดตรวจทุก diff ที่แตะเงิน
บังคับใน CLAUDE.md ไม่ใช่ทางเลือก
