## วิธีจัดทีมคืนนี้ และเหตุผล

ลูกพี่สั่งให้ใช้สภาเจไดแบบไม่เปลือง token

**เลือกรันทีละตัว ไม่รันขนาน** — ขนานต้องแยก worktree แล้วมา merge
ซึ่งค่า merge กับค่าตามแก้ conflict แพงกว่าเวลาที่ประหยัดได้ และคืนนี้มีเวลาเหลือเฟือ
สิ่งที่แพงจริงในงานแบบนี้คือ**รอบตรวจซ้ำ** ไม่ใช่เวลารอ

วิธีประหยัด token ที่ใช้:
- บรีฟแต่ละตัวให้ละเอียดพอที่มันไม่ต้องไปไล่อ่านทั้ง repo เอง
- สั่งให้ตอบกลับ ≤200 คำ ไม่ให้ส่งเนื้อไฟล์กลับมา
- ให้ agent เขียนเทสต์ที่ยืนยันกฎด้วยตัวเอง แทนที่ผมจะไปไล่ตรวจทีละบรรทัด
- mace-windu ตรวจเป็นก้อน ไม่ใช่ตรวจทีละไฟล์
