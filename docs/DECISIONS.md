### D-011 · พิสูจน์แล้วว่า Money Invariants กันได้จริงที่ระดับ DB
ไม่ได้เชื่อว่าเขียน trigger แล้วจะทำงาน — ลองละเมิดจริงทีละข้อ

| ทดสอบ | ผล |
|---|---|
| รายการไม่สมดุล (Dr 12,000 / Cr 9,999) | ✅ ถูกปฏิเสธ + rollback ทั้งชุด |
| บรรทัดเงินสดไม่ผูกบัญชีธนาคาร | ✅ ถูกปฏิเสธ |
| รายการที่ถูกต้อง | ✅ บันทึกได้ตามปกติ |
| ลบรายการที่บันทึกแล้ว | ✅ ถูกปฏิเสธ ให้ใช้ reverse |
| Corporate ไม่แนบหลักฐาน | ✅ ถูกปฏิเสธ |
| Corporate แนบหลักฐานแล้ว | ✅ บันทึกได้ |

**หมายเหตุทางเทคนิค**: trigger ตรวจสมดุลเป็น `deferrable initially deferred`
คือ fire ตอน **COMMIT** ไม่ใช่ตอน INSERT — จำเป็น เพราะระหว่างใส่บรรทัดแรก
รายการยังไม่สมดุลโดยธรรมชาติ ผลคือ application จะรู้ว่าผิดตอน commit
ซึ่งถูกต้องแล้ว (ทั้งรายการเข้าหรือไม่เข้าเลย ไม่มีครึ่งๆ กลางๆ)

การทดสอบรอบแรกรายงานผิดว่าข้อ 1 ไม่ผ่าน เพราะสคริปต์ลบข้อมูลทิ้งก่อน commit
จึงไม่ทัน trigger — ทดสอบซ้ำแบบปล่อยให้ commit จริงแล้วยืนยันว่ากันได้
