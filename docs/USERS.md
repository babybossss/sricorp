## `super_admin` ต่างจาก `management` ตรงไหน

ต่างกัน **สิทธิ์เดียว** คือ `users.manage` — สร้าง/ปิดผู้ใช้ · ย้ายระดับ · ติ๊กสิทธิ์ ·
มอบสิทธิ์เห็นผู้ถือ · นอกนั้นเหมือนกันหมด (อนุมัติรายการ · ยืนยันเงิน · ยกเลิกรายการ ·
เปิดงวด · ตั้งค่าระบบ · เห็นทุกผู้ถือ · เห็นภาพรวมการลงทุน)

> ⚠️ ตอนนี้ **ทั้ง 4 ท่านเป็นระดับบริหารทั้งหมด** จึงยังไม่มีการแบ่งแยกหน้าที่
> ถ้าวันหนึ่งอยากให้บางคนดูได้แต่แก้ไม่ได้ ใช้ระดับ `manager` หรือเพิ่ม `viewer`

## ⚠️ ลำดับที่ต้องทำ — ข้ามไม่ได้

`app_users.id` เป็น **foreign key ไป `auth.users(id)`** แปลว่า
**ต้องมีตัวตนในระบบล็อกอินก่อน ถึงจะให้สิทธิ์ได้** ลัดไม่ได้

```
1. เปิด Google login ให้เสร็จ
2. ทั้ง 4 ท่าน เข้าเว็บแล้ว "เข้าสู่ระบบด้วย Google" คนละหนึ่งครั้ง
   → ตอนนี้จะยัง **เข้าไปแล้วไม่เห็นอะไรเลย** ซึ่ง **ถูกต้อง**
     (ไม่มีแถวใน app_users = ไม่มีสิทธิ์อะไรเลย · ระบบออกแบบให้เงียบ ไม่ใช่ error)
3. บอกผมว่าใครเข้าแล้วบ้าง → ผมใส่ระดับให้
4. ออกแล้วเข้าใหม่ → เห็นครบตามระดับ
```

**ทางเลือกที่เร็วกว่าข้อ 2**: ลูกพี่เชิญทั้ง 4 อีเมลจากหน้า Supabase
(Authentication → Users → **Invite user**) ซึ่งสร้างแถวใน `auth.users` ให้เลย
โดยไม่ต้องรอให้แต่ละคนเข้ามาเอง · แล้วผมใส่ระดับได้ทันที

## คำสั่งที่จะใช้ (รันหลังทุกคนมีตัวตนแล้ว)

```sql
insert into sri_os.app_users (id, email, display_name, role, is_active)
select u.id, u.email, v.display_name, v.role, true
  from (values
    ('babiesboss@gmail.com',   'ธนากร ศรีชัยธำรง', 'super_admin'),
    ('thanawins9@gmail.com',   'ธนวินท์',          'management'),
    ('sutee.pbc@gmail.com',    'สุธี',             'management'),
    ('b.intorpetch@gmail.com', 'เบ็ญจพร',          'management')
  ) as v(email, display_name, role)
  join auth.users u on lower(u.email) = v.email
on conflict (id) do update
  set role = excluded.role,
      display_name = excluded.display_name,
      is_active = true;
```

**ทำไมเขียนแบบ `join auth.users`** — ถ้าใครยังไม่เคยเข้าระบบ แถวนั้นจะ **ไม่ถูกสร้างเงียบๆ**
แทนที่จะพังทั้งคำสั่งหรือสร้างด้วย id มั่ว · รันซ้ำได้ (`on conflict`)
**ต้องเช็คหลังรันเสมอว่าได้ครบ 4 แถว** ถ้าได้ไม่ครบ แปลว่าคนนั้นยังไม่เคยล็อกอิน
