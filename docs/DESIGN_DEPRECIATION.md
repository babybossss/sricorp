# ค่าเสื่อมราคา — สถานะและแบบที่เสนอ

> เขียน 09/10 · **ยังไม่ได้ทำ** รอลูกพี่อนุมัติ
> ตอบคำถาม "ค่าเสื่อมออกแบบไว้ยังไง" — คำตอบตรงๆ คือ **ยังไม่ได้ออกแบบเลย**

## สถานะวันนี้ · ไม่มีเลยทั้งระบบ

ตรวจแล้วทั้ง `src/` `supabase/` `docs/`

| | |
|---|---|
| บัญชีค่าเสื่อมราคาในผังบัญชี | **ไม่มี** |
| บัญชีค่าเสื่อมราคาสะสม | **ไม่มี** |
| หมวดรายการค่าเสื่อม | **ไม่มี** (54 หมวดไม่มีเลย) |
| ฟิลด์อายุการใช้งานในทะเบียนทรัพย์ | **ไม่มี** |
| โค้ดคำนวณ | **ไม่มี** |

โผล่ครั้งเดียวใน `docs/PLAN.md:476` ในรายการ "เฟสหลัง" คู่กับ VAT และ multi-currency

## ต้องทำไหม — แยกตามฝั่ง

| ฝั่ง | ต้องมีค่าเสื่อมไหม | เพราะ |
|---|---|---|
| **นิติบุคคล** (SRI Corporation / Holding / Capital) | **ต้องมี** | งบการเงินส่ง DBD · ค่าเสื่อมเป็นค่าใช้จ่ายที่หักภาษีได้ตาม ภ.ง.ด.50 ถ้าไม่ลง = เสียภาษีเกินจริง |
| **บุคคล** (5 คน) | **ไม่ต้องมี** | บุคคลธรรมดาไม่ทำงบ · ค่าเช่าหักค่าใช้จ่ายเหมาจ่าย 30% หรือหักจริง ค่าเสื่อมไม่มีผลทางภาษี |

→ **ค่าเสื่อมเป็นเรื่องของ `corporate_strict` เท่านั้น** ฝั่งบุคคลต้องปิดไว้
ไม่ใช่ปิดด้วยการ "ไม่กรอก" แต่ต้องกันที่ตารางกฎ ไม่งั้นงบฝั่งบุคคลจะมีค่าใช้จ่ายที่ไม่มีอยู่จริง

## 🔴 ตัวบล็อกจริง 2 ข้อ — ต้องแก้ก่อน ไม่ใช่หลัง

### 1 · ผังบัญชีรวมที่ดินกับอาคารไว้รหัสเดียว

`1500 อสังหาริมทรัพย์เพื่อการลงทุน` ถือทั้งที่ดินและอาคาร

**ที่ดินไม่คิดค่าเสื่อมตลอดกาล · อาคารคิด 5% ต่อปี (20 ปี)**

ถ้าไม่แยกก่อน จะคิดค่าเสื่อมไม่ได้เลย เพราะไม่รู้ว่าก้อนไหนเป็นอาคาร

**เรื่องที่ด่วน**: ลูกพี่ยังไม่ได้นำเข้ายอดยกมา — ถ้านำเข้าทั้งก้อนที่ `1500`
แล้วมาแยกทีหลัง ต้องลงรายการจัดประเภทใหม่ทุกหลัง และราคาที่แยกย้อนหลัง
จะไม่มีเอกสารรองรับ (สรรพากรถามได้ว่าแบ่งจากอะไร)

→ **แยกตอนนำเข้าครั้งแรกถูกกว่าเยอะ** ใช้ราคาประเมินกรมธนารักษ์แยกที่ดิน/สิ่งปลูกสร้าง
หรือสัดส่วนในสัญญาซื้อขาย เป็นหลักฐานได้

เสนอ: `1500` ที่ดิน · `1520` อาคารและสิ่งปลูกสร้าง · `1590` ค่าเสื่อมราคาสะสม (ติดลบ)

### 2 · ขายทรัพย์คิดกำไรจากราคาทุน ซึ่งจะผิดทันทีที่มีค่าเสื่อม

`inv.sell_re` วันนี้: `dr 1100 / cr 1500` + กำไรเข้า `4300` ขาดทุนเข้า `5910`
คิดกำไรเทียบ **ราคาทุน**

พอมีค่าเสื่อม ต้องคิดเทียบ **ราคาตามบัญชี (ทุน − ค่าเสื่อมสะสม)** และต้องล้าง
ค่าเสื่อมสะสมของหลังนั้นออกพร้อมกัน

ตัวอย่างที่พลาดได้: อาคารทุน 10 ล้าน ค่าเสื่อมสะสม 4 ล้าน ขาย 8 ล้าน
- คิดแบบวันนี้ → **ขาดทุน 2 ล้าน** ❌
- คิดถูก → ราคาตามบัญชี 6 ล้าน → **กำไร 2 ล้าน** ✅

ผิดไป 4 ล้าน และผิดทิศ — จากขาดทุนเป็นกำไร **ซึ่งกระทบภาษีเต็มจำนวน**

→ **ค่าเสื่อมกับการขายทรัพย์ต้องทำพร้อมกัน แยกทำไม่ได้**
ถ้าเปิดค่าเสื่อมแต่ไม่แก้การขาย = บทเรียนข้อ 7 ของ `mace-windu`
("เปิดฟีเจอร์ครึ่งเดียวอันตรายกว่าไม่เปิด")

## แบบที่เสนอ

### ผังบัญชี (+4 รหัส)
| รหัส | ชื่อ | ประเภท |
|---|---|---|
| `1520` | อาคารและสิ่งปลูกสร้าง | asset |
| `1590` | ค่าเสื่อมราคาสะสม — อาคาร | asset (ติดลบ) |
| `1591` | ค่าเสื่อมราคาสะสม — ส่วนปรับปรุง | asset (ติดลบ) |
| `5600` | ค่าเสื่อมราคา | expense |

`1500` เปลี่ยนความหมายเป็น **ที่ดิน** เท่านั้น — ต้องเปลี่ยนชื่อให้ชัด
ไม่งั้นคนลงรายการเก่าจะเข้าใจผิด

### ทะเบียนทรัพย์ (+4 ฟิลด์)
`land_value` · `building_value` · `useful_life_years` (ตั้งต้น 20) ·
`depreciation_start_date` (วันที่เริ่มใช้งาน ไม่ใช่วันที่ซื้อ)

### หมวดรายการใหม่ 1 หมวด
`dep.monthly` ค่าเสื่อมราคาประจำเดือน · `dr 5600 / cr 1590`
- `cash: "none"` · **ไม่เข้างบกระแสเงินสด** (ไม่มีเงินไหล)
- `requires: ["asset"]` · ใช้ได้เฉพาะ `corporate_strict`
- วิธี: เส้นตรง (straight-line) เท่านั้น — ตรงกับที่สรรพากรยอมและคนอ่านเข้าใจ

### Automation — สร้างได้แค่ร่าง (กฎเหล็กข้อ 6)
cron สิ้นเดือน → สร้าง **draft** รายการค่าเสื่อมของทุกอาคารที่เข้าเงื่อนไข
**ห้าม post เอง** · ลูกพี่หรือผู้มีสิทธิ์อนุมัติกดยืนยัน

### ด่านที่ต้องมี (ไม่มี = ตัวเลขเพี้ยนเงียบๆ)
1. **ค่าเสื่อมสะสมห้ามเกินราคาทุน** ของทรัพย์นั้น (หักมูลค่าคงเหลือ)
   ไม่กัน = คิดค่าเสื่อมเลยปีที่ 20 ไปเรื่อยๆ ค่าใช้จ่ายโผล่จากอากาศ
2. **ห้ามคิดค่าเสื่อมที่ดิน** — กันที่ตารางกฎ ไม่ใช่ที่หน้าจอ
3. **ห้ามคิดซ้ำเดือนเดียวกันของทรัพย์เดียวกัน** (cron รันซ้ำ / กดอนุมัติสองรอบ)
4. **ขายทรัพย์ต้องล้างค่าเสื่อมสะสมของทรัพย์นั้นออกครบ** ไม่งั้นค่าเสื่อมสะสม
   ของทรัพย์ที่ขายไปแล้วค้างในงบดุลตลอดกาล
5. **ปิดฝั่ง `personal_flexible`** ที่ตารางกฎ

## คำแนะนำเรื่องลำดับ

**ขั้น 1 ควรทำก่อนนำเข้ายอดยกมา** เพราะแยกที่ดิน/อาคารตอนนำเข้าถูกกว่าแยกย้อนหลังมาก
ส่วนขั้น 2–4 รอได้ถึงก่อนปิดงบปีแรกของนิติบุคคล

**ที่ต้องถามลูกพี่**
1. นิติบุคคลทั้ง 3 ตัวมีอาคารในชื่อตัวเองจริงไหม หรือทรัพย์อยู่ชื่อบุคคลหมด
   (ถ้าอยู่ชื่อบุคคลหมด ค่าเสื่อมเลื่อนไปได้ไม่ต้องรีบ)
2. ที่ดิน/อาคารแยกราคากันได้ไหมจากเอกสารที่มี (โฉนด · สัญญาซื้อขาย · ราคาประเมิน)
3. อายุการใช้งานใช้ 20 ปีตามสรรพากรทั้งหมด หรือมีหลังที่ต่างออกไป
