**30/09/2026** · ถ้าสรุปไม่ทันเลื่อนเป็น 31/10/2026 ได้ แต่ต้องเลื่อน**ทั้งไฟล์พร้อมกัน**
ยอดตั้งต้นที่คนละวันกันทำให้งบดุลไม่ลงตัวและหาสาเหตุไม่ได้

## ไฟล์ 1 — ผังบัญชีและหมวดงบ

| ชีท | แก้ได้ไหม |
|---|---|
| ผังบัญชี | แก้ชื่อ เพิ่มบัญชี ปิดใช้งานได้ · **ห้ามเปลี่ยนรหัสที่มีรายการแล้ว** |
| โครงงบดุล | สลับลำดับ รวม/แยกบรรทัดได้ |
| โครงงบกำไรขาดทุน | เหมือนกัน |
| ตารางกฎหมวดย่อย | **อ่านเพื่อตรวจเท่านั้น** คู่บัญชีถูกบังคับด้วยเทสต์ในโค้ด |

เพิ่มบัญชีใหม่ต้องใส่ในชีทโครงงบด้วย ไม่งั้นยอดจะหายจากรายงานเงียบๆ — ระบบมีเทสต์กันไว้

## ไฟล์ 2 — ยอดตั้งต้นงบดุล

หนึ่งชีทต่อหนึ่งผู้ถือ (6 ชีท) + ชีทรวมที่คำนวณให้ + ชีทพอร์ตลงทุนรายล็อต

- ใส่ **ราคาทุน/ตามบัญชี** ไม่ใช่ราคาประเมิน (ราคาประเมินอยู่ในไฟล์ 3 ชีททรัพย์สิน)
- ใส่จำนวนบวกเสมอ ระบบรู้เดบิต/เครดิตจากประเภทบัญชี
- เงินสดแยกทีละบัญชีธนาคาร แล้วต้องรวมได้เท่าบรรทัด 1100
- **พอร์ตลงทุนกรอกทีละล็อต** (วันที่ซื้อ + จำนวน + ราคา) **ไม่ใช่ต้นทุนเฉลี่ย**
  ระบบคิดต้นทุนถัวเฉลี่ยให้เองจากล็อต ลูกพี่ไม่ต้องคำนวณเฉลี่ยมาให้
  ที่ต้องกรอกรายล็อตเพราะ **ค่าเฉลี่ยคำนวณจากล็อตได้ แต่ล็อตย้อนสร้างจากค่าเฉลี่ยไม่ได้**
- **ล็อตที่เป็นสกุลเงินต่างประเทศ ต้องใส่อัตราแลกเปลี่ยนวันซื้อด้วย** (คอลัมน์ `อัตรา ณ วันซื้อ`)
  หุ้นต่างประเทศและคริปโตเข้าข้อนี้ · ไม่ใส่อัตรา ระบบจะ**ปฏิเสธทั้งไฟล์** ไม่เดาให้
  เพราะถ้าเดาอัตรา ต้นทุนจะผิดและกำไรตอนขายจะผิดตามไปทั้งก้อน
- ไม่มีบรรทัด "เงินถอนของเจ้าของ" — เป็นยอดระหว่างงวด ถอนสะสมถูกหักในกำไรสะสมแล้ว

ช่องตรวจล่างสุดของแต่ละชีทต้องเป็น **0** (เขียวแล้วถือว่าใช้ได้)
ถ้ายังไม่ตรง ใส่ผลต่างที่ **3300 กำไรสะสม** พร้อมหมายเหตุ แล้วแยกทีหลังว่าส่วนไหนเป็นทุน
ส่วนไหนเป็นเงินกู้กรรมการ — **อย่าดัดตัวเลขอื่นให้ตรง**

## ไฟล์ 3 — แจกแจงทรัพย์สิน (`SRI_OS_3_แจกแจงทรัพย์สิน.xlsx`)

> **เรื่องชื่อไฟล์:** ไฟล์นี้คือ "ไฟล์ 3" ตามชื่อไฟล์ของมัน · ส่วน `SRI_OS_ข้อมูลตั้งต้น.xlsx`
> (หัวข้อถัดไป) เป็นไฟล์เดิมที่ **ไม่มีหมายเลข** แต่เอกสารเก่าบางที่ยังเรียกว่า "ไฟล์ 3"
> เวลาอ่านเอกสารอื่นให้ดูชื่อไฟล์เป็นหลัก ไม่ใช่หมายเลข

**ไฟล์นี้ตัวนำเข้าอ่านจริงแล้ว (27/10) และ "ขาดไม่ได้"** — ก่อนหน้านี้มีเทมเพลตแต่ระบบไม่อ่าน

ทำไมต้องมี: ยอดในชีท `BS-*` ของไฟล์ 2 เป็น **ยอดรวมต่อรหัสบัญชี** ถ้าลงสมุดเป็นบรรทัดรวม
ทรัพย์แต่ละชิ้นจะ **ไม่มีต้นทุนรายชิ้น** แล้ว **ขายไม่ออกตลอดไป** (ด่านปฏิเสธการขายเมื่อต้นทุน = 0)
ไฟล์นี้คือสิ่งที่ทำให้คอนโดสองห้องเป็นสองชิ้นที่ขายแยกกันได้ ไม่ใช่ยอดก้อนเดียว

| | |
|---|---|
| ชีทที่ต้องกรอก | `แจกแจงทรัพย์` (อีกชีทคือ `อ่านก่อน`) |
| แถวข้อมูล | 6–205 |
| คอลัมน์ | A ถือในชื่อ \* · B รหัสทรัพย์ · C ชื่อทรัพย์ \* · D บรรทัดในงบดุล \* · E ต้นทุน \* · F ค่ารีโนเวทสะสม · G หมายเหตุ |

**บรรทัดงบดุลที่ต้องแจกแจง** — `1500` · `1520` · `1510` · `1300` · `1320` · `1400` · `1410` · `1600`
บัญชีอื่นกรอกยอดรวมในไฟล์ 2 ได้ตามเดิม

### กติกาสี่ข้อที่ระบบบังคับ

1. **ผลบวกต้องเท่าไฟล์ 2 ทุกสตางค์** — ต่อ (ผู้ถือ × รหัสบัญชี) · ไม่เท่า = **ปฏิเสธทั้งไฟล์**
   พร้อมบอกว่าต่างกันที่ช่องไหน เท่าไร · ระบบ **ไม่เฉลี่ย ไม่ปัดให้ลง ไม่ลงบรรทัดส่วนต่าง**
2. **ไฟล์ 2 มียอดแต่ไม่มีบรรทัดแจกแจง = ปฏิเสธ** — ไม่ใช่ลงเป็นยอดรวมให้เงียบๆ
   เพราะนั่นคือทรัพย์ที่ขายไม่ออก ซึ่งเป็นบั๊กที่ไฟล์นี้มาแก้
3. **ไม่มีชีทแจกแจงเลย = ปฏิเสธ** (ชีทว่างผ่านได้ ถ้าไฟล์ 2 ไม่มียอดในบรรทัดที่ต้องแจกแจง)
4. **แถวตัวอย่างในเทมเพลตต้องลบก่อนอัป** — แถวที่หมายเหตุยังขึ้นต้นว่า "ตัวอย่าง" จะถูกปฏิเสธ
   พร้อมบอกเลขแถว · ระบบ **ไม่ข้ามแถวนั้นให้** เพราะการข้ามข้อมูลที่คนกรอกเงียบๆ อันตรายกว่า

### สองข้อที่ต่างจากที่คาด

- **ค่ารีโนเวท (คอลัมน์ F)** ไปลงบัญชี `1510` ซึ่งเป็นบัญชี **ร่วม** ของทั้งเพื่อการเช่าและเพื่อการขาย
  แต่ยัง **ผูกกับทรัพย์ชิ้นเดิม** → ตอนขายถูกตัดออกพร้อมทรัพย์ และตอนย้ายวัตถุประสงค์ไม่ต้องย้าย
- **`1600` เงินมัดจำจ่าย ไม่ลงทะเบียนเป็นทรัพย์** — ผังหมวดทรัพย์ประกาศไว้ว่าไม่ใช่การลงทุน
  (เงินวางประกัน รอคืน) และทางคืนเงินมัดจำบังคับ "ผู้ติดต่อ" ไม่ใช่ "ทรัพย์"
  → แจกแจงไว้เพื่อ **กระทบยอด** (ยังบังคับให้เท่าไฟล์ 2) แต่ลงสมุดเป็นยอดรวมของบัญชี
  และชื่อรายการที่กรอกไว้ไปอยู่ในหมายเหตุของบรรทัดนั้น ไม่หายไป

### ส่งไฟล์เข้าระบบ

ที่หน้า `/import` เลือกได้ **ทางใดทางหนึ่ง**:
- ใส่ชีท `แจกแจงทรัพย์` ไว้ในไฟล์ยอดตั้งต้น (ไฟล์ 2) เลย **หรือ**
- แนบไฟล์ `SRI_OS_3` แยกในช่อง "ไฟล์แจกแจงทรัพย์สิน"

**ส่งทั้งสองทางพร้อมกัน = ปฏิเสธ** (ระบบไม่เลือกข้างให้ว่าจะเชื่อชุดไหน)

ต้องมีสิทธิ์ `asset.manage` + `portfolio.view_all` ด้วย ถ้าการนำเข้าต้องลงทะเบียนทรัพย์ใหม่

## ไฟล์ข้อมูลตั้งต้น (`SRI_OS_ข้อมูลตั้งต้น.xlsx`)

ไฟล์เดิมที่ส่งไปแล้ว ไม่ได้เปลี่ยนโครงสร้าง แต่**ชีท 8 พอร์ตลงทุนใช้แทนกันไม่ได้**
กับชีทรายล็อตในไฟล์ 2 — ชีท 8 เก็บ**ต้นทุนเฉลี่ย** ซึ่งละเอียดไม่พอ (ย้อนแยกเป็นล็อตไม่ได้)
ให้ใช้ชีทรายล็อตในไฟล์ 2 แทน · ถ้ากรอกชีท 8 ไปแล้วไม่เสียเปล่า ใช้ยอดรวมตรวจทานกันได้

### 8 ชีท เรียงตามลำดับที่ต้องกรอก

| # | ชีท | ทำไมต้องกรอกลำดับนี้ |
|---|---|---|
| 1 | ผู้ใช้ & สิทธิ์ | ตั้งค่า login ก่อน |
| 2 | บัญชีเงิน | ทุกการเคลื่อนไหวเงินต้องผูกบัญชีจากชีทนี้ |
| 3 | ผู้ติดต่อ | ชีท 5 และ 7 อ้างชื่อจากที่นี่ |
| 4 | ทรัพย์สิน | ชีท 5 อ้างรหัสทรัพย์จากที่นี่ |
| 5 | สัญญา | ผูกทรัพย์ + ผู้ติดต่อ → ระบบสร้างตารางงวดให้ |
| 6 | หนี้สิน | รวมช่อง "ผลต่างรอกระทบยอด" |
| 7 | ค้างรับ | ทำหน้า AR aging |
| 8 | พอร์ตลงทุน | หุ้น กองทุน คริปโต ทอง |

### กติกาที่ฝังไว้ในเทมเพลต

- ช่องมีดาว `*` = บังคับ (หัวสีแดงอ่อน) · ไม่มีดาว = เว้นว่างได้ แต่จะขึ้นเตือนใน Data health
- ช่องที่มีตัวเลือกตายตัวเป็น dropdown กันสะกดไม่ตรงกัน
- แถวสีเทาเอียง = ตัวอย่าง ลบทิ้งได้
- **วันตัดยอดต้องเป็นวันเดียวกันทุกชีท** ไม่งั้นงบดุลไม่ลงตัว

### ข้อที่คนกรอกผิดบ่อยที่สุด

ทั้งสี่ข้อนี้เขียนไว้ในชีท "เริ่มที่นี่" ด้วย เพราะเคยผิดจริงใน Excel เดิม

1. **เงินกู้ ≠ รายได้** — เงินที่กู้มาเข้าบัญชีเป็นหนี้สิน ลงชีท 6
2. **เงินต้น ≠ ค่าใช้จ่าย** — เงินต้นที่คืนลดหนี้สิน มีแต่ดอกเบี้ยที่เป็นค่าใช้จ่าย
3. **ปล่อยกู้/ขายฝาก = สินทรัพย์** — เงินที่เราปล่อยออกไปเป็นลูกหนี้ ลงชีท 4
4. **ผลต่างรอกระทบยอด** — ถ้ายอดไม่ตรง อย่าปรับตัวเลขอื่นให้ตรง ให้ใส่เป็นบรรทัดแยกในชีท 6 แล้วหาทีหลัง
