## วันตัดยอด

**30/09/2026** · ถ้าสรุปไม่ทันเลื่อนเป็น 31/10/2026 ได้ แต่ต้องเลื่อน**ทั้งไฟล์พร้อมกัน**
ยอดตั้งต้นที่คนละวันกันทำให้งบดุลไม่ลงตัวและหาสาเหตุไม่ได้

## ไฟล์ 1 — ผังบัญชีและหมวดงบ

| ชีท | แก้ได้ไหม |
|---|---|
| ผังบัญชี | แก้ชื่อ เพิ่มบัญชี ปิดใช้งานได้ · **ห้ามเปลี่ยนรหัสที่มีรายการแล้ว** |
| โครงงบดุล | สลับลำดับ รวม/แยกบรรทัดได้ |
| โครงงบกำไรขาดทุน | เหมือนกัน |
| ตารางกฎหมวดย่อย | **อ่านเพื่อตรวจเท่านั้น** คู่บัญชีถูกบังคับด้วยเทสต์ในโค้ด |

เพิ่มบัญชีใหม่ต้องใส่ในชีทโครงงบด้วย ไม่งั้นยอดจะหายจากรายงานเงียบๆ — ระบบมีเทสต์กันไว้

## ไฟล์ 2 — ยอดตั้งต้นงบดุล

หนึ่งชีทต่อหนึ่งผู้ถือ (6 ชีท) + ชีทรวมที่คำนวณให้ + ชีทพอร์ตลงทุนรายล็อต

- ใส่ **ราคาทุน/ตามบัญชี** ไม่ใช่ราคาประเมิน (ราคาประเมินอยู่ในไฟล์ 3 ชีททรัพย์สิน)
- ใส่จำนวนบวกเสมอ ระบบรู้เดบิต/เครดิตจากประเภทบัญชี
- เงินสดแยกทีละบัญชีธนาคาร แล้วต้องรวมได้เท่าบรรทัด 1100
- **พอร์ตลงทุนกรอกทีละล็อต** (วันที่ซื้อ + จำนวน + ราคา) เพราะใช้ FIFO
  ถ้ากรอกต้นทุนเฉลี่ย จะคิด FIFO ทีหลังไม่ได้เลย
- ไม่มีบรรทัด "เงินถอนของเจ้าของ" — เป็นยอดระหว่างงวด ถอนสะสมถูกหักในกำไรสะสมแล้ว

ช่องตรวจล่างสุดของแต่ละชีทต้องเป็น **0** (เขียวแล้วถือว่าใช้ได้)
ถ้ายังไม่ตรง ใส่ผลต่างที่ **3300 กำไรสะสม** พร้อมหมายเหตุ แล้วแยกทีหลังว่าส่วนไหนเป็นทุน
ส่วนไหนเป็นเงินกู้กรรมการ — **อย่าดัดตัวเลขอื่นให้ตรง**

## ไฟล์ 3 — ข้อมูลตั้งต้น

ไฟล์เดิมที่ส่งไปแล้ว ไม่ได้เปลี่ยนโครงสร้าง แต่**ชีท 8 พอร์ตลงทุนใช้แทนกันไม่ได้**
กับชีทรายล็อตในไฟล์ 2 — ชีท 8 เก็บต้นทุนเฉลี่ย ซึ่งคิด FIFO ไม่ได้ ให้ใช้ชีทรายล็อตในไฟล์ 2 แทน

### 8 ชีท เรียงตามลำดับที่ต้องกรอก

| # | ชีท | ทำไมต้องกรอกลำดับนี้ |
|---|---|---|
| 1 | ผู้ใช้ & สิทธิ์ | ตั้งค่า login ก่อน |
| 2 | บัญชีเงิน | ทุกการเคลื่อนไหวเงินต้องผูกบัญชีจากชีทนี้ |
| 3 | ผู้ติดต่อ | ชีท 5 และ 7 อ้างชื่อจากที่นี่ |
| 4 | ทรัพย์สิน | ชีท 5 อ้างรหัสทรัพย์จากที่นี่ |
| 5 | สัญญา | ผูกทรัพย์ + ผู้ติดต่อ → ระบบสร้างตารางงวดให้ |
| 6 | หนี้สิน | รวมช่อง "ผลต่างรอกระทบยอด" |
| 7 | ค้างรับ | ทำหน้า AR aging |
| 8 | พอร์ตลงทุน | หุ้น กองทุน คริปโต ทอง |

### กติกาที่ฝังไว้ในเทมเพลต

- ช่องมีดาว `*` = บังคับ (หัวสีแดงอ่อน) · ไม่มีดาว = เว้นว่างได้ แต่จะขึ้นเตือนใน Data health
- ช่องที่มีตัวเลือกตายตัวเป็น dropdown กันสะกดไม่ตรงกัน
- แถวสีเทาเอียง = ตัวอย่าง ลบทิ้งได้
- **วันตัดยอดต้องเป็นวันเดียวกันทุกชีท** ไม่งั้นงบดุลไม่ลงตัว

### ข้อที่คนกรอกผิดบ่อยที่สุด

ทั้งสี่ข้อนี้เขียนไว้ในชีท "เริ่มที่นี่" ด้วย เพราะเคยผิดจริงใน Excel เดิม

1. **เงินกู้ ≠ รายได้** — เงินที่กู้มาเข้าบัญชีเป็นหนี้สิน ลงชีท 6
2. **เงินต้น ≠ ค่าใช้จ่าย** — เงินต้นที่คืนลดหนี้สิน มีแต่ดอกเบี้ยที่เป็นค่าใช้จ่าย
3. **ปล่อยกู้/ขายฝาก = สินทรัพย์** — เงินที่เราปล่อยออกไปเป็นลูกหนี้ ลงชีท 4
4. **ผลต่างรอกระทบยอด** — ถ้ายอดไม่ตรง อย่าปรับตัวเลขอื่นให้ตรง ให้ใส่เป็นบรรทัดแยกในชีท 6 แล้วหาทีหลัง
